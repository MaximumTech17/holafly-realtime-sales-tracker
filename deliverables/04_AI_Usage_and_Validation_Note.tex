\section{Quantitative Validation Checks Performed on All AI-Generated Outputs}
AI output was never accepted unverified. Every SQL gate, KPI formula, UI render, and edge case was validated through an automated \textbf{15-test \code{pytest} suite} (\code{tests/test\_sales\_tracker.py}) plus headless Streamlit \code{AppTest} and browser visual inspection:

\begin{itemize}[leftmargin=1.15em, itemsep=2.0pt, topsep=2pt, label=\hbullet]
  \item \textbf{1. Deduplication \& Exact Uniqueness (\code{T-02}):} Asserted \code{COUNT(*) == COUNT(DISTINCT order\_id)} on \code{v\_valid\_sales} and confirmed every injected 2nd and 3rd webhook retry is quarantined with \code{occurrence\_rank > 1} and \code{dq\_status = 'DUPLICATE'}.
  \item \textbf{2. Real Sale Monetary Rule \& Test-Account Exclusions (\code{T-03}, \code{T-04}, \code{T-05}):} Asserted $\min(\text{amount\_usd}) > \$0.00$ in valid sales (100\% exclusion of $\$0$ failed captures and negative refunds) while verifying legitimate high-value B2B/group bundles ($\$640.00 > \$500.00$) are \textbf{accepted} with no arbitrary upper cap; verified zero internal QA emails and zero missing dimensions.
  \item \textbf{3. Partition Conservation \& KPI Reconciliation (\code{T-06}, \code{T-07}):} Verified exact row conservation (\code{Raw == Valid + Duplicates + Invalid\_Amount + Test\_Email + Missing\_Dimension}, delta $= 0$) and cross-checked \code{SUM(amount\_usd) / COUNT(*) == AOV} directly against raw SQLite queries.
  \item \textbf{4. Anomaly Sensitivity, False-Alarm Guard \& Organic Baseline (\code{T-08}, \code{T-14}):} Verified \textbf{CRITICAL DROP} fires on the active mid-shift drop, \textbf{SURGE} fires on the \code{FLASH20} spike, \textbf{NORMAL} holds on steady organic baseline traffic ($\text{std} \geq 1.2$ across 10m buckets, fixing an early flat-line artifact), and alerts suppress cleanly when $\mu_{\text{base}} < 10.0$ on small slices.
  \item \textbf{5. SLA Latency, Midnight Shift, Cloud Boot, UI HTML Integrity \& PDF Audit (\code{T-09}--\code{T-15}):} Verified \textbf{Freshness Lag $\leq 3.0$\,min} ($\leq 10$\,min SLA), tested midnight-crossing \code{SHIFT\_3\_NIGHT} (\code{22:00--05:59 COT}) on full UTC timestamps, verified ephemeral container boot recovery, caught and fixed a Markdown 4-space HTML indentation bug so zero raw HTML tags leak to the UI (asserted in \code{T-15} alongside official SVG logo rendering), and asserted via \code{PyMuPDF} that both LaTeX PDFs are strictly \textbf{1 page} with \textbf{0 emojis}.
\end{itemize}
